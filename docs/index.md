# Personal MCP

Static project page for [personal_mcp](https://github.com/AdhimulamBhargavSaiViswanath-05/personal_mcp).

**This site does not run the MCP server.** GitHub Pages only hosts documentation. The server runs on your Mac (Cursor, stdio) or later on [Render](https://render.com) (HTTP).

## What it does

| Tool | Purpose |
|------|---------|
| `personal_ping` | Health check |
| `personal_add_note` / `personal_list_notes` | Local learning notes |
| `personal_add_application` / `personal_list_applications` / `personal_update_application_status` | Job tracker (you paste Naukri/LinkedIn **links**; no scraping) |
| `personal_github_*` | Read-only GitHub API (needs `GITHUB_TOKEN` in `.env`) |

## Phases

1. **Now** — stdio + Cursor on your laptop  
2. **Optional** — GitHub PAT for read tools  
3. **Later** — Deploy same code on Render as `streamable-http` + `MCP_API_KEY`
